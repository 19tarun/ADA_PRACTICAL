# 📘 Algorithm and Data Structures Programs in C++

This repository contains a collection of C++ programs that implement core algorithms and data structures. These implementations are useful for academic purposes, technical interviews, and competitive programming.

---

## 📁 Contents

### 🔍 Searching Algorithms
- `binarysearch.cpp` – Binary Search (Iterative/Recursive)
- `1dpeak.cpp` – 1D Peak Finding
- `2dpeak.cpp` – 2D Peak Finding
- `maxmin.cpp` – Find Maximum and Minimum using Divide and Conquer

### 🔃 Sorting Algorithms
- `Bubblesort.cpp` – Bubble Sort
- `insertionsort.cpp` – Insertion Sort
- `Quicksort.cpp` – Recursive Quick Sort
- `iterativequicksort.cpp` – Iterative Quick Sort
- `mergesort.cpp` – Merge Sort

### 📊 Graph Algorithms
- `dijkstra.cpp` – Dijkstra's Algorithm
- `allpairsp.cpp` – All Pairs Shortest Path (Floyd-Warshall)
- `GraphColouring.cpp` – Graph Coloring using Backtracking
- `kruskals.cpp` – Kruskal's Minimum Spanning Tree
- `prims.cpp` – Prim's Minimum Spanning Tree

### 📐 Dynamic Programming
- `MCM.cpp` – Matrix Chain Multiplication
- `MGP.cpp` – Maximum Gain Path / Game Strategy
- `knapsack01` – 0/1 Knapsack Problem

### ♟️ Backtracking Algorithms
- `NQueens.cpp` – N-Queens Problem

### 🧠 Divide and Conquer
- `maxmin.cpp` – Maximum and Minimum Element
- `strassen.cpp` – Strassen’s Matrix Multiplication Algorithm

### 🔢 Miscellaneous
- `magicSquare.cpp` – Generate Magic Square
- `README.md` – Project Overview and Instructions
